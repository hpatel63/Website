Chief Motel — Wix Embed Site (Custer, SD)

This repo contains a sleek, Apple-style, one-page HTML designed to be embedded in a Wix site using Add → Embed → Custom Embeds → Embed a widget → Enter Code.

What’s inside
	•	index.html – the full one-page site (hero, sticky booking bar, highlights, rooms, gallery, nearby, contact/map, reviews, SEO schema).
	•	No build step required – copy/paste into Wix’s HTML iframe app.

How to embed in Wix (quick)
	1.	Wix Editor → Add → Embed → Custom Embeds → Embed a Widget.
	2.	Click Enter Code, choose Code, paste all of index.html.
	3.	Stretch the iframe to full width; set Height ~ 3500px (or Auto if available).
	4.	Publish.

Tip: Update phone/email if needed. The current details are for Chief Motel — Custer, South Dakota.

Customization
	•	Colors & radii: edit CSS variables in :root at the top of index.html.
	•	Swap phone/WhatsApp: change tel: and wa.me links.
	•	Replace gallery images: update the Unsplash URLs in the Gallery and Rooms sections.
	•	Map: the Google Maps embed URL is in the Contact + Map section; change query or coordinates as needed.
	•	SEO: update <title>, <meta name="description">, and the JSON-LD Hotel schema at the bottom of the file.

Booking options

This demo bar triggers a phone call. To use a real booking engine (Cloudbeds, Little Hotelier, Wix Form):
	•	Replace the <form class="bar"> onsubmit handler with your booking link or form action.
	•	Or add a Wix App (Forms / Bookings) and link the CTA button to that widget.
